System Architecture

Engineered for Autonomous Velocity

Git assumes decentralized human commits on local packfiles. OpenScion decouples source control into content-addressed Merkle chunks, virtual loopback filesystems, and in-memory speculative rebase queues.

FastCDC Chunking & Merkle CAS

Files are sliced into content-defined chunks (average 64 KB) using FastCDC. Files sharing duplicate code across branches consume zero extra bytes. Stored in content-addressable storage (SHA-256).

  • Sub-file deduplication across millions of changesets
  • Zero-cost snapshot creation in under 3ms
  • Eliminates "git gc" and repack lock contention

0-Byte Virtual Ghost VFS

Mount any historical revision or branch instantly into ./mnt. Millions of files consume 0 bytes of disk. Directory traversal (ls, find) runs at memory speed; file contents stream from CAS only when read() is issued.

  • Native OS loopback WebDAV — zero kernel extensions
  • Zero macFUSE or driver reboots required
  • Sub-second sparse clones for ephemeral agent pods

Speculative Merge Queue

Eliminates Git's global branch ref lock bottleneck (refs/heads/*). Agents submit changesets to an in-memory rebase pipeline that verifies AST diffs and lands changes strictly linearly on the WAL.

  • Sustains 50,000+ automated merges per day
  • 0.00ms branch lock wait time (lock-free WAL)
  • Strict linear sequence graph (#1, #2, #3...)

Command Line Interface

CLI Command Reference

Works directly in your terminal like git with zero learning curve. Click any command to test it in the terminal above.

scion init [name]
scion init my-monorepo

Initialize standalone repository in current directory with embedded Merkle CAS and SQLite WAL.

scion status [-v]
scion status

Inspect working tree status, dirty files, staged diffs, sequence number, and active agent model context.

scion diff [-s] [file]
scion diff -s

Colorized unified diff viewer with per-file hunks or clean summary diffstat view.

scion commit -m <msg>
scion commit -m "feat: auth" --agent claude-code-3.7-sonnet

Record atomic Merkle changeset with AI agent model, session tokens, and SHA-256 tree root.

scion mount [dir]
scion mount ./mnt

Mount virtual ghost filesystem with zero disk footprint over native OS loopback WebDAV.

scion clone <src> [dir]
scion clone ./repo ./agent-pod --sparse "services/auth/**"

Sub-second monorepo clone with sparse path filtering. Virtualizes non-matching paths instantly.

scion log [-n count]
scion log

View strictly linear DAG timeline with sequence numbers (#1, #2, #3), authors, and agent tags.

scion blame <file>
scion blame services/auth/token.go

Line-by-line attribution showing commit sequence numbers, authors, and AI agent model provenance.

scion serve [--port]
scion serve --port 8080

Launch central team server and merge queue (supports SQLite WAL & PostgreSQL/CockroachDB).
